.. _configure:

Configure
---------

* **Sales ‣ Configuration ‣ Settings**: *Product Variants*, *Units of
  Measure*, *Pricing* (one price, pricelists per customer segment or
  formulas) and the default *Invoicing Policy*.
* **Sales ‣ Configuration ‣ Products**: *Attributes*, *Attribute Values*,
  *Units of Measure* and, in developer mode, *Product Categories*.
* **Purchases ‣ Configuration ‣ Settings**: vendor pricelists, warnings on
  products, costing method.
* **Inventory ‣ Configuration ‣ Settings**: lots and serial numbers,
  packaging, routes.
* **Accounting**: income and expense accounts and the costing method of a
  :field:`category <categ_id>` apply to all its products; default taxes are
  set in **Accounting ‣ Configuration ‣ Settings**.
