.. _example:

Example
-------

**Products running out**

Choose the :version:`11|*Exhausted Stock*;*|*Negative Forecasted Quantity*`
filter (Inventory installed): the storable products with no quantity
:version:`11|on hand;*|forecasted`.

**Prices of a pricelist**

Type the pricelist name in the search bar and select *Search Pricelist for:
…*: the price shown on each product is the one of that pricelist.

**Print the labels of some products**

Select the products with the check boxes, then **Print ‣**
:version:`11|**Products Labels**;*|**Product Label (PDF)**`.
