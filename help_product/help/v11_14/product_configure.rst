.. _configure:

How to set up
-------------

* **Sales ‣ Configuration ‣ Settings**: :version:`11|*Attributes and
  Variants*;12|*Variants and Options*;*|*Variants*`, *Units of Measure*,
  pricelists and the default *Invoicing Policy*.
* **Sales ‣ Configuration ‣ Products**: *Attributes*\ :version:`12|, *Attribute
  Values*`\ :version:`<=14| and *Units of Measure*`;
  :version:`15|**Sales ‣ Configuration ‣ Units of Measure**: the units and
  their categories`.
* :version:`11|**Purchases**;*|**Purchase**` **‣ Configuration ‣ Settings**:
  vendor pricelists, warnings on products.
* **Inventory ‣ Configuration ‣ Settings**: lots and serial numbers,
  packagings, multi-step routes; **Inventory ‣ Configuration ‣ Product
  Categories**: the categories.
* **Invoicing**: income and expense accounts and the costing method of a
  :field:`category <categ_id>` apply to all its products; default taxes are
  set in **Invoicing ‣ Configuration ‣ Settings**.
