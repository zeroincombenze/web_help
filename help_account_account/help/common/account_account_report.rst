.. _report:

Report and export file
----------------------

The accounts have no printable report of their own; they are used by the
accounting reports of the **Reporting** menu and by the journal items of
**Invoicing ‣ Accounting**.

* The button **Balance** of the form opens the journal items of the account.
* To get a file of the accounts, select them in the list view, then
  **Actions ‣ Export**: choose the fields and the format (xlsx or csv). See
  *Import and Export data* in the **Ready** page of the help.
* To load many accounts, use the gear icon next to the breadcrumb ‣
  **Import records**: the link *Import Template for Chart of Accounts* downloads
  the sample file. In the *Account Name* column the code and the name may be
  written together, e.g. *101000 Current Assets*.
