How to update a record
----------------------

#. Open the account from the list and change the fields: the form is saved
   automatically when you leave it. In the list you can also change the code,
   the name, the type and the *Allow Reconciliation* switch in place.
#. The :field:`type <account_type>` can be changed even if the account has
   journal items, with the limits told in the FAQ: check the reports of the
   closed years afterwards, because the type decides if the balance is carried
   forward.
#. The :field:`code <code>` can be changed at any time: the journal items
   keep the account. Check that the new code is unique in the company.
#. To change the *Default Taxes* and the *Tags*, use the fields of the
   **Accounting** tab. The default taxes are proposed when you post an entry
   on the account; off-balance accounts cannot have them.
#. With several companies, the tab **Mapping** (shown only to users of
   several companies) lists one *Code* for each company where the account
   is shared.
#. To split an account shared by several companies into one account per
   company, open it and use the gear icon ‣ **Unmerge account** (accounting
   managers; in the list **Actions ‣ Unmerge account**).
   To merge duplicated accounts, select them in the list and use **Actions ‣
   Merge accounts**.
