.. _search:

Suggestions for search
----------------------

* **Invoicing ‣ Configuration ‣ Accounting ‣ Chart of Accounts** lists the
  accounts.
* Type in the search bar to find an account by name or by the start of its
  code, e.g. ``15`` finds every account whose code begins with 15.
* The panel at the left lists the first two characters of the codes: click
  one to see only those accounts.
* **Filters**: *Receivable*, *Payable*, *Equity*, *Assets*, *Liability*,
  *Income*, *Expenses*; *Account with Entries*, the accounts already used in
  journal items; *Active Account*, on by default, which hides the deprecated
  accounts. You can also search the :field:`type <account_type>`.
* **Group By ‣ Account Type** groups the accounts by type.
