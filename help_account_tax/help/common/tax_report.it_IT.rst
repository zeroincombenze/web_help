.. _report:

Stampe ed esportazione
----------------------

Le imposte non hanno una stampa propria; sono stampate sui documenti che le
usano:

* Il PDF della fattura mostra l':field:`etichetta su fatture <invoice_label>`
  delle imposte, le :field:`note legali <invoice_legal_notes>` delle imposte
  usate e i totali raggruppati per :field:`gruppo imposta <tax_group_id>`.
* L'IVA italiana è riportata nel report fiscale della contabilità, tramite le
  *Griglie imposta* delle righe di ripartizione delle imposte.
* Per avere un file delle imposte, selezionarle nella lista, poi **Azioni ‣
  Esporta**: scegliere i campi e il formato (xlsx o csv). Vedere *Importazione
  ed esportazione dati* nella pagina **Pronto** dell'aiuto.
