.. _search:

Suggestions for search
----------------------

* **Invoicing ‣ Configuration ‣ Accounting ‣ Taxes** lists the taxes.
* Type in the search bar to search the taxes by name, description or amount,
  e.g. ``22`` finds *22%* and *22% S*. In a multi-company database you can
  search by company.
* **Filters**: *Sale* and *Purchase* (both selected when the list opens),
  *Services* and *Goods* (the tax scope), *Active* and *Inactive*.
* **Group By**: *Company* (multi-company database), *Tax Type* and *Tax
  Scope*.
