.. _report:

Report and export file
----------------------

* **Quotation / Order**: the PDF of the quotation or of the confirmed order.
  :version:`<=12|Press **Print** in the header, or use the **Print** menu
  above the form;*|Use the **Print** menu above the form`, or select the orders
  in the list and use **Print**.
* **Send by Email** attaches the same PDF to the email; the sent message and
  its attachment stay in the chatter of the order.
* Sales analysis: **Sales ‣ Reporting ‣ Sales** shows the ordered and invoiced
  amounts by period, salesperson, customer or product, as graph or pivot.
* To get a file of the sale orders, select them in the list view, then
  **Action ‣ Export**: choose the fields and the format (xlsx or csv). See
  *Import and Export data* in the **Ready** page of the help.
