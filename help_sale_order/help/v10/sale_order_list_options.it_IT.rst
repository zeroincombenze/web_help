.. _options:

Opzioni
-------

* **Filtri**: *I miei ordini* mostra solo i propri documenti; *Preventivi*,
  *Preventivi inviati*, *Vendite*, *Da fatturare* e *Upselling* restringono
  l'elenco.
* **Raggruppa per**: addetto vendite, cliente o mese ordine, con i subtotali.
* :field:`Stato fatturazione <invoice_status>`: *Niente da fatturare*,
  *Da fatturare*, *Completamente fatturato* o *Opportunità di upselling*.
