.. _example:

Esempi
------

**Ordini di un cliente ancora da fatturare**

Scegliere il filtro *Da fatturare*, digitare il nome del cliente nella barra di
ricerca e selezionare *Cerca Cliente per: …*; il totale appare in fondo
all'elenco.

**Vendite mensili di ogni addetto vendite**

Scegliere il filtro *Vendite*, poi **Raggruppa per ‣ Commerciale** e
**Raggruppa per ‣ Mese Ordine**: ogni gruppo mostra il suo subtotale.

**Stampare più preventivi**

Selezionare i preventivi con le caselle di spunta, poi **Stampa ‣ Preventivo /
Ordine**.
