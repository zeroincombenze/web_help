.. _example:

Example
-------

**Orders of a customer still to invoice**

Choose the *To Invoice* filter, type the customer name in the search bar and
select *Search Customer for: …*; the total is shown at the bottom of the list.

**Monthly sales of each salesperson**

Choose the *Sales* filter, then **Group By ‣ Salesperson** and
**Group By ‣ Order Month**: each group shows its subtotal.

**Print several quotations**

Select the quotations with the check boxes, then **Print ‣ Quotation / Order**.
