.. _usage:

Utilizzo
--------

* **Vendite ‣ Vendite ‣ Preventivi** elenca i preventivi, **Vendite ‣ Vendite
  ‣ Ordini di vendita** gli ordini confermati, **Vendite ‣ Fatturazione ‣
  Vendite da fatturare** gli ordini in attesa di fattura.
* Premere **Crea** per creare un preventivo; fare clic su una riga per aprirlo.
* Scrivere nella barra di ricerca per trovare un cliente, un prodotto o un
  numero d'ordine.
* Selezionare più righe per stamparle, esportarle o eliminarle dal menu
  **Azione**.
