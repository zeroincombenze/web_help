.. _usage:

Usage
-----

* **Sales ‣ Sales ‣ Quotations** lists the quotations, **Sales ‣ Sales ‣
  Sales Orders** the confirmed orders, **Sales ‣ Invoicing ‣ Sales to
  Invoice** the orders waiting for an invoice.
* Press **Create** to create a quotation; click a row to open it.
* Type in the search bar to find a customer, a product or an order number.
* Select several rows to print, export or delete them from the **Action**
  menu.
