Sale orders
===========

.. _description:

Description
-----------

The list of quotations and sales orders. Each row shows the
:field:`number <name>`, the :field:`customer <partner_id>`, the
:field:`salesperson <user_id>`, the :field:`total <amount_total>` and the
progress of the document.
