.. _usage:

Utilizzo
--------

* **Vendite ‣ Ordini ‣ Preventivi** elenca i preventivi, **Vendite ‣ Ordini ‣
  Ordini** gli ordini confermati, **Vendite ‣ Da fatturare ‣ Ordini da
  fatturare** gli ordini in attesa di fattura.
* Premere **Nuovo** per creare un preventivo; fare clic su una riga per aprirlo.
* Scrivere nella barra di ricerca per trovare un cliente, un prodotto o un
  numero d'ordine.
* Selezionare più righe per stamparle, esportarle o annullarle dal menu
  **Azioni**.
