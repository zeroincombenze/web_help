.. _usage:

Usage
-----

* **Sales ‣ Orders ‣ Quotations** lists the quotations, **Sales ‣ Orders ‣
  Orders** the confirmed orders, **Sales ‣ To Invoice ‣ Orders to Invoice**
  the orders waiting for an invoice.
* Press **New** to create a quotation; click a row to open it.
* Type in the search bar to find a customer, a product or an order number.
* Select several rows to print, export or cancel them from the **Actions** menu.
