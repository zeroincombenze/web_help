.. _example:

Esempi
------

**Ordini di un cliente ancora da fatturare**

Scegliere il filtro *Da fatturare*, digitare il nome del cliente nella barra di
ricerca e selezionare *Ricerca Cliente per: …*; il totale appare in fondo
all'elenco.

**Vendite mensili di ogni addetto vendite**

Scegliere il filtro *Ordini di vendita*, poi **Raggruppa per ‣ Addetto
vendite** e **Raggruppa per ‣ Data ordine ‣ Mese**: ogni gruppo mostra il suo
subtotale. Salvare la ricerca con **Preferiti ‣ Salva ricerca corrente** per
riutilizzarla.

:version:`>=18|**Stampare o inviare più preventivi**;
*|**Stampare più preventivi**`

Selezionare i preventivi con le caselle di spunta, poi :version:`16|**Stampa ‣
Preventivo / Ordine**;*|**Stampa ‣ Quotation / Order**`\ :version:`>=18| oppure
**Azioni ‣ Invia e-mail**`.
