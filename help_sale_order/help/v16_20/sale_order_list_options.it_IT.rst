.. _options:

Opzioni
-------

* **Filtri**: *I miei preventivi* e *I miei ordini* mostrano solo i propri
  documenti; *Preventivi*, *Ordini di vendita*, *Da fatturare* e *Da
  proporre upselling* restringono l'elenco.
* **Raggruppa per**: addetto vendite, cliente o data ordine, con i subtotali.
* :field:`Stato fatturazione <invoice_status>`: *Niente da fatturare*,
  *Da fatturare*, *Completamente fatturato* o *Opportunità di upselling*.
* Le colonne opzionali si mostrano o nascondono dal menu a destra delle
  intestazioni delle colonne.
