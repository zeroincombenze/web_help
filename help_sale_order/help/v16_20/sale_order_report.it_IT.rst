.. _report:

Stampe
------

* :version:`16|**Preventivo / Ordine**;*|**Quotation / Order**`: il PDF del
  preventivo o dell'ordine confermato. Si stampa dal menu **Stampa**\
  :version:`>=17| (sotto l'icona dell'ingranaggio accanto al nome del record)`,
  oppure dall'elenco dopo aver selezionato gli ordini.
* **Invia con e-mail** allega lo stesso PDF all'e-mail; il messaggio inviato e
  il suo allegato restano nel chatter dell'ordine. Il cliente può scaricare il
  PDF dal portale (**Anteprima**).
* **Fattura proforma** (impostazione *Fattura proforma*): si stampa dal menu
  **Stampa** o si invia con **Invia fattura PROFORMA**.
* Analisi vendite: **Vendite ‣ Rendicontazione ‣ Vendite** mostra gli importi
  ordinati e fatturati per periodo, addetto vendite, cliente o prodotto, come
  grafico o tabella pivot.
