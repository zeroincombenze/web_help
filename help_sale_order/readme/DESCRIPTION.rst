Context help pages for the sale order list and form, shown by web_context_help.

Every page has the same structure:

* **Description**: what quotations and sales orders are
* **Usage**: step-by-step guide, from the quotation to the invoice
* **Options**: the main optional fields and filters
* **Configuration**: the Sales settings that affect sale orders

Pages are in English and Italian, with the menus and settings of the running
Odoo version.
