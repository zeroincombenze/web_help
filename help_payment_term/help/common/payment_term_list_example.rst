.. _example:

Example
-------

**Find the end of month terms**

Type ``end%month`` in the search bar and search the name: the list shows
e.g. *30 Days End of Month* and *30 Days End of Month + 5*, but not *30
Days*.

**Terms of a partner**

The list does not show which partners use the terms: open the partners list
and use the *Payment Terms* field in a custom filter or a custom group.
