Install all the context help pages

Installa tutte le pagine di aiuto contestuale

Unknown description_img

Meta module: installing it installs web_context_help and all the help modules, with their context help pages in English and Italian:

  • help_account_invoice: customer invoices and vendor bills
  • help_payment_term: payment terms
  • help_product: products and product variants
  • help_purchase_order: requests for quotation and purchase orders
  • help_res_partner: contacts (partners)
  • help_sale_order: quotations and sale orders

The module has no code nor data of its own. Each help module also installs the Odoo application it explains (Invoicing, Sales, Purchases).

Modulo contenitore: installarlo installa web_context_help e tutti i moduli di aiuto, con le loro pagine di aiuto contestuale in inglese e in italiano:

  • help_account_invoice: fatture clienti e fatture fornitori
  • help_payment_term: termini di pagamento
  • help_product: prodotti e varianti di prodotto
  • help_purchase_order: richieste di preventivo e ordini di acquisto
  • help_res_partner: contatti (partner)
  • help_sale_order: preventivi e ordini di vendita

Il modulo non ha codice né dati propri. Ogni modulo di aiuto installa anche l'applicazione Odoo che spiega (Fatturazione, Vendite, Acquisti).
