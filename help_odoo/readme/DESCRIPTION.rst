Installs in one step all the context help modules, shown by web_context_help:

* **help_account_invoice**: customer invoices and vendor bills
* **help_payment_term**: payment terms
* **help_product**: products and product variants
* **help_purchase_order**: purchase orders
* **help_res_partner**: contacts
* **help_sale_order**: sale orders

The module has no content of its own: installing it also installs the apps
the help modules depend on (Invoicing, Sales, Purchase, Contacts).
