.. _search:

Suggestions for search
----------------------

* The dashboard opens with the *Favorites* filter: only the journals marked
  with the ★ star of **More ‣ Favorite**. Remove it with its ✕ to see every
  journal of the company. Do not mix it up with the **Favorites** menu of the
  search bar, which keeps your saved searches.
* Type in the search bar to find a *Journal* by name or short code.
* **Filters** on the type: *Sale*, *Purchase*, *Liquidity* (cash and bank),
  *Miscellaneous*, and *Favorites*. *Add Custom Filter* builds any
  condition.
* **Favorites ‣ Save current search** keeps the filters for later; tick *Use
  by default* to open the dashboard with them.
