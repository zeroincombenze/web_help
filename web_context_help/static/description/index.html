Context help button, pages written in RST by each module

Pulsante di aiuto contestuale, pagine scritte in RST da ogni modulo

Unknown description_img

Adds a |sos| button to the control panel of every view: it opens the help of the current view in a separate window, so the Odoo tab stays usable.

  • Help pages are written in RST by each module, in its help/ directory
  • The help window follows the navigation (Follow Odoo), highlights the fields named by the page and can start a guided tour
  • Questions are answered by a full-text search over the help sections; every question is logged for the administrator
  • Administrators can edit a page; the edited version survives the upgrades and a warning appears when the original source changes
  • A page can be chosen by a field of the open record, many2one included: by the :when: of its RST source or by rules set by the administrator, e.g. a different sale order help for each order type
  • Views without a page get an automatic page built from the fields help
  • The Help menu opens the help home page; its Summary button lists the pages of every installed help module (e.g. help_account_invoice, help_sale_order)

Configuration | Configurazione

No configuration is needed. Pages are rebuilt at server start when a help source changes; a help editor can force it with Rebuild all pages in Help > Help Editor > Help Pages.

Every internal user reads the help. The help pages and their rules are written by the users of the group Help Editor (Settings > Users, section Context Help), with no administrator rights: opening the Help app, they get its Help Editor menu in the top bar (pages, rules, questions asked) and the Edit button of the help window. The administrators are help editors too.

The videos inserted in the help pages are read from the directory of the system parameter web_help_video_path (default ~/Video, the home of the user running Odoo), subdirectories included; change it in Settings > Technical > System Parameters.

Non serve configurazione. Le pagine sono ricostruite all'avvio del server quando cambia una sorgente di aiuto; un editor dell'aiuto può forzarlo con Ricostruisci tutte le pagine in Aiuto > Editor dell'aiuto > Pagine di aiuto.

Ogni utente interno legge l'aiuto. Le pagine di aiuto e le loro regole sono scritte dagli utenti del gruppo Editor dell'aiuto (Impostazioni > Utenti, sezione Aiuto contestuale), senza diritti di amministratore: aprendo l'app Aiuto, hanno il suo menu Editor dell'aiuto nella barra in alto (pagine, regole, domande poste) e il pulsante Modifica della finestra di aiuto. Anche gli amministratori sono editor dell'aiuto.

I video inseriti nelle pagine di aiuto sono letti dalla cartella del parametro di sistema web_help_video_path (predefinito ~/Video, la home dell'utente che esegue Odoo), sottocartelle comprese; si cambia in Impostazioni > Tecnico > Parametri di sistema.

Usage | Utilizzo

The Help menu, at the top of the menu tree, opens the help home page in the help window. The Summary button in the header lists, grouped by module, the pages of every installed help module; Ready goes back to the home page. Users allowed to change the help pages also see Edit, which opens the page in the backend: the home page itself can be adapted like any other page. In the editor, the film button of the floating toolbar (or the /Help video command) lists the videos of the video directory: the chosen one is inserted after the current paragraph, as a player started by a click. To remove a video, press Backspace in the line after it or Delete in the line before it. In developer mode the </> button shows the HTML code of the page.

Press the |sos| button in the control panel. Pages are looked up by view xmlid, then by model and view type, then by model; otherwise an automatic page lists the fields help.

The box in the help window header finds text in the page, like the browser Ctrl+F (which focuses it). Case and accents are ignored, line breaks and bold or linked words too. With several words, words of 1-2 letters are ignored and only the places where all of them are within 12 words in the same paragraph are shown; when there is no such place, every occurrence of every word is shown and the counter says any word. Text in quotes ("draft invoice") is searched as an exact phrase. Enter / ▼ and Shift+Enter / ▲ go to the next / previous match, Esc clears the search.

The FAQ section of a page and the fields help of its model are shown on their own pages, opened by the FAQ and Fields buttons in the help window header; the Help button goes back to the page. The questions built by help-question :auto: are left to the Fields page.

Writing help for a module: put RST files in help/common/ or in the directory of a group of Odoo versions (help/v10, help/v11_14, help/v15, help/v16_20); a group file overrides the common one with the same name. Italian twins are named page.it_IT.rst.

Every page has these sections, in this order, with their label: description (summary of the view / model), new_record (form only: steps to insert a record), update_record (form only: steps to update a record), search (list only: how to search and group by), configure (how to configure the model), report (how to show the report or the pdf attachment), example (useful examples), faq (frequently asked questions, help-question blocks), footer (date and time of page creation and copyright notice). A section that does not apply keeps one line saying so.

.. help-page:: partner :title: Partners :model: res.partner :view: base.view_partner_form :view-type: form :when: is_company = True :priority: 96

.. help-include:: common_part.rst

.. help-inherit:: other_module.partner :section: usage :position: after

RST added after the section labelled "usage"

.. help-question:: How do I add a tag?

Use the :field:`Tags <category_id>` field.

.. help-question:: :auto:

:when: shows the page only when the open record (its selection, boolean and many2one fields) or the menu (its default_<field> context keys) match: conditions field = value, field != value, several values joined by comma, several conditions joined by and. When the value is unknown the page is not used, e.g. move_type != entry keeps the invoice help away from the journal entries, which share the invoice form. A many2one value is the xmlid or the id of the record, e.g. type_id = sale_order_type.normal_sale_type; False means empty. Among the pages of the same priority that can be shown, the one meeting more conditions wins: a page with :when: beats the page without it.

Rules

Without writing RST, a help editor chooses which page is shown from Help ‣ Help Editor ‣ Help Rules or from the Rules tab of a page: field of the page model (selection, boolean or many2one), *is* or is not, and the values (selection), the checkbox (boolean) or the record (many2one). A page with rules is shown when one of them is met, and the :when: of its source too.

The rules apply to the Clear cut pages only: a clear cut page is shown only when one of its rules is met. Every page has a Priority, 1 being the highest. The clear cut pages are checked first, in priority order: the first one with a rule met is shown. With no rule met, the general page (not clear cut, its rules ignored) with the highest priority is shown. The pages of the administrator get 32 by default, the pages built from the modules 96: these are the last fallback, always available. The priority of a module page is set by the :priority: option of its help-page, 96 when missing.

A clear cut page, or a page of priority 64 or less, shows the Loose help button in the help window: it opens the general page of priority 64 or more with the highest priority, for the same record, usually the page of the module.

Example: sale orders with a different help for each OCA sale_order_type. Create a page per type (Help Pages ‣ New: key, title, model sale.order, view type form, content), check Clear cut and add to it the rule Type is <the type>. Orders of the other types keep the standard sale order help. A page created this way, or by Duplicate of the standard page (key followed by " (copy)"), has no source: it is kept by the rebuild of the pages.

:position: is one of before, after, replace, remove. :auto: builds the questions from the fields help of the page model.

A page shows only the text of the running Odoo version: put version specific blocks in help-version and version specific words in the :version: role; the version directories remain for whole files that differ.

.. help-version:: >=17

RST shown on Odoo 17 and later (sections allowed)

Press :version:`16|Create and View Invoice;17|Create Draft Invoice;>=18|Create Draft`.

Conditions: 16, 16-18, >=17, >17, <=16, <17, * (any version), several joined by comma (10,16). The role shows the text of the first matching condition, inline markup allowed, roles not allowed; write \ before the role when it is glued to the previous word. Roles :field: and :tour: highlight a field or run a tour in the Odoo tab.

.. |sos| unicode:: U+1F6DF

Il menu Aiuto, in cima all'albero dei menu, apre la pagina iniziale dell'aiuto nella finestra di aiuto. Il pulsante Sommario nell'intestazione elenca, raggruppate per modulo, le pagine di ogni modulo di aiuto installato; Pronto torna alla pagina iniziale. Gli utenti abilitati a modificare le pagine di aiuto vedono anche Modifica, che apre la pagina nel backend: anche la pagina iniziale può essere adattata come ogni altra pagina. Nell'editor, il pulsante con la pellicola della barra mobile (o il comando /Video di aiuto) elenca i video della cartella dei video: quello scelto è inserito dopo il paragrafo corrente, come lettore avviato con un clic. Per togliere un video, premere Backspace nella riga dopo o Canc nella riga prima. In modalità sviluppatore il pulsante </> mostra il codice HTML della pagina.

Premere il pulsante |sos| del pannello di controllo. La pagina è cercata per xmlid della vista, poi per modello e tipo vista, poi per modello; altrimenti una pagina automatica elenca l'aiuto dei campi.

La casella nell'intestazione della finestra di aiuto cerca un testo nella pagina, come Ctrl+F del browser (che la seleziona). Maiuscole e accenti sono ignorati, come gli a capo e le parole in grassetto o con link. Con più parole quelle di 1-2 lettere sono ignorate e sono mostrati solo i punti in cui sono tutte entro 12 parole nello stesso paragrafo; se non ce ne sono, è mostrata ogni occorrenza di ogni parola e il contatore indica qualsiasi parola. Il testo tra virgolette ("bozza fattura") è cercato come frase esatta. Invio / ▼ e Maiusc+Invio / ▲ passano all'occorrenza successiva / precedente, Esc annulla la ricerca.

La sezione Domande frequenti di una pagina e l'aiuto dei campi del suo modello sono mostrati in pagine a parte, aperte dai pulsanti FAQ e Campi nell'intestazione della finestra di aiuto; il pulsante Aiuto torna alla pagina. Le domande costruite da help-question :auto: sono lasciate alla pagina Campi.

Scrivere l'aiuto di un modulo: mettere i file RST in help/common/ o nella cartella di un gruppo di versioni Odoo (help/v10, help/v11_14, help/v15, help/v16_20); il file del gruppo prevale su quello comune con lo stesso nome. I gemelli italiani si chiamano pagina.it_IT.rst.

Ogni pagina ha queste sezioni, in quest'ordine, con la loro etichetta: description (sintesi della vista / modello), new_record (solo form: passi per inserire un record), update_record (solo form: passi per modificare un record), search (solo lista: come cercare e raggruppare), configure (come configurare il modello), report (come visualizzare la stampa o l'allegato pdf), example (esempi utili), faq (domande frequenti, blocchi help-question), footer (data e ora di creazione della pagina e nota di copyright). Una sezione che non si applica contiene una riga che lo dice.

.. help-page:: partner :title: Partner :model: res.partner :view: base.view_partner_form :view-type: form :when: is_company = True :priority: 96

.. help-include:: parte_comune.rst

.. help-inherit:: altro_modulo.partner :section: usage :position: after

RST aggiunto dopo la sezione con etichetta "usage"

.. help-question:: Come aggiungo un'etichetta?

Usare il campo :field:`Etichette <category_id>`.

.. help-question:: :auto:

:when: mostra la pagina solo quando il record aperto (i suoi campi di selezione, booleani e many2one) o il menu (le sue chiavi di contesto default_<campo>) corrispondono: condizioni campo = valore, campo != valore, più valori separati da virgola, più condizioni unite da and. Quando il valore non è noto la pagina non è usata, ad es. move_type != entry tiene l'aiuto delle fatture lontano dalle registrazioni contabili, che usano la stessa maschera delle fatture. Il valore di un many2one è l'xmlid o l'id del record, ad es. type_id = sale_order_type.normal_sale_type; False significa vuoto. Tra le pagine della stessa priorità che possono essere mostrate vince quella che soddisfa più condizioni: una pagina con :when: prevale sulla pagina senza.

Regole

Senza scrivere RST, un editor dell'aiuto sceglie quale pagina mostrare da Aiuto ‣ Editor dell'aiuto ‣ Regole di aiuto o dalla scheda Regole di una pagina: campo del modello della pagina (selezione, booleano o many2one), *è* o non è, e i valori (selezione), la casella (booleano) o il record (many2one). Una pagina con regole è mostrata quando una di esse è soddisfatta, e anche il :when: della sua sorgente.

Le regole valgono solo per le pagine Clear cut: una pagina clear cut è mostrata solo quando una delle sue regole è soddisfatta. Ogni pagina ha una Priorità, 1 è la più alta. Le pagine clear cut sono controllate per prime, in ordine di priorità: è mostrata la prima con una regola soddisfatta. Se nessuna regola è soddisfatta, è mostrata la pagina generale (non clear cut, le sue regole sono ignorate) con la priorità più alta. Le pagine dell'amministratore hanno 32 come predefinito, quelle costruite dai moduli 96: sono l'ultima alternativa, sempre disponibile. La priorità di una pagina di modulo è data dall'opzione :priority: del suo help-page, 96 se manca.

Una pagina clear cut, o di priorità 64 o inferiore, mostra nella finestra di aiuto il pulsante Aiuto generale: apre la pagina generale di priorità 64 o superiore con la priorità più alta, per lo stesso record, di solito la pagina del modulo.

Esempio: ordini di vendita con un aiuto diverso per ogni sale_order_type OCA. Creare una pagina per tipo (Pagine di aiuto ‣ Nuovo: chiave, titolo, modello sale.order, tipo vista form, contenuto), spuntare Clear cut e aggiungere la regola Tipo è <il tipo>. Gli ordini degli altri tipi mantengono l'aiuto standard dell'ordine di vendita. Una pagina creata così, o con Duplica della pagina standard (chiave seguita da " (copy)"), non ha sorgente: è conservata dalla ricostruzione delle pagine.

:position: vale before, after, replace o remove. :auto: costruisce le domande dall'aiuto dei campi del modello della pagina.

Una pagina mostra solo il testo della versione di Odoo in uso: mettere i blocchi specifici di una versione in help-version e le parole specifiche nel ruolo :version:; le cartelle per versione restano per i file interi che cambiano.

.. help-version:: >=17

RST mostrato da Odoo 17 in poi (sezioni ammesse)

Premere :version:`16|Crea e visualizza fattura;17|Crea bozza fattura;>=18|Crea bozza`.

Condizioni: 16, 16-18, >=17, >17, <=16, <17, * (qualsiasi versione), più condizioni separate da virgola (10,16). Il ruolo mostra il testo della prima condizione soddisfatta, con il markup in linea ma senza altri ruoli; scrivere \ prima del ruolo quando è attaccato alla parola precedente. I ruoli :field: e :tour: evidenziano un campo o avviano un tour nella scheda di Odoo.
