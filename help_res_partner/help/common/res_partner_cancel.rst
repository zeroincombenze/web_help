How to archive or delete record
-------------------------------

#. A contact no longer used is archived: it is hidden from lists and
   selections but stays on the documents that use it.
   :version:`<=12|In the form press [\`Active\`] at the top right;<=16|In the
   form use **Action ‣ Archive**;*|In the form use the gear icon ‣
   **Archive**`, or select the contacts in the list view and use
   :version:`<=16|**Action ‣ Archive**;*|**Actions ‣ Archive**`.

   .. help-version:: 12-14

      A contact linked to a portal or internal user cannot be archived:
      archive the user first.

   .. help-version:: >=15

      A contact linked to an active user cannot be archived: archive the
      user first.

#. The *Archived* filter shows the archived contacts;
   :version:`<=12|open one and press [\`Archived\`] to restore it;<=16|select
   them and use **Action ‣ Unarchive** to restore them;*|select them and use
   **Actions ‣ Unarchive** to restore them`.
#. To delete a contact, open it and use :version:`<17|**Action ‣
   Delete**;*|the gear icon ‣ **Delete**`, or select the contacts in the list
   view and use :version:`<=16|**Action ‣ Delete**;*|**Actions ‣ Delete**`. A
   contact used by orders, invoices or journal entries cannot be deleted:
   archive it instead.\ :version:`>=15| A contact linked to an active user
   cannot be deleted either.`
